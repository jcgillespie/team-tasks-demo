<task type="auto">
  <name>Task 1: Bootstrap script for remote state backend</name>
  <files>infra/bootstrap/create-state-backend.sh</files>
  <action>
Create `infra/bootstrap/create-state-backend.sh` — a one-shot Azure CLI script that provisions the OpenTofu remote state backend. This script must be idempotent (safe to run twice via `--output none` and `||true` patterns).

Script must:
1. Accept variables at the top: `RESOURCE_GROUP`, `STORAGE_ACCOUNT`, `CONTAINER_NAME`, `LOCATION` (with sensible defaults like `teamtasks-tfstate-rg`, `teamtaskstfstate`, `tfstate`, `eastus`)
2. Run `az group create --name $RESOURCE_GROUP --location $LOCATION`
3. Run `az storage account create --name $STORAGE_ACCOUNT --resource-group $RESOURCE_GROUP --sku Standard_LRS --encryption-services blob --allow-blob-public-access false --https-only true --min-tls-version TLS1_2`
4. Run `az storage container create --name $CONTAINER_NAME --account-name $STORAGE_ACCOUNT --auth-mode login`
5. Print the storage account name and container name at the end for use in backend configs
6. Add a comment block at the top explaining: "Run this ONCE before first `tofu init`. Not managed by OpenTofu (prevents circular dependency)."

Make the script executable (`chmod +x` via a note in the file header comment: "Run: bash infra/bootstrap/create-state-backend.sh").
  </action>
  <verify>
    <automated>bash -n infra/bootstrap/create-state-backend.sh && echo "bootstrap script syntax OK"</automated>
  </verify>
  <done>Script exists, passes bash syntax check, contains idempotent az CLI commands for storage account + container creation with TLS 1.2 and no public blob access</done>
</task>

  <action>
Create six OpenTofu modules under `infra/modules/`. Each module has `main.tf`, `variables.tf`, and `outputs.tf`. Use `azurerm` provider (no version constraint in modules — pin only in root envs).

**Standard tag locals block (add to every module's main.tf):**
```hcl
locals {
  tags = merge(var.tags, {
    environment = var.environment
    project     = "teamtasks"
    managed-by  = "opentofu"
  })
}
```

____

**Module: resource-group**
- `main.tf`: `azurerm_resource_group` using `var.name`, `var.location`, `local.tags`
- `variables.tf`: `name` (string), `location` (string, default `"eastus"`), `environment` (string), `tags` (map(string), default `{}`)
- `outputs.tf`: `name`, `location`, `id`

____

**Module: identity**
- `main.tf`: `azurerm_user_assigned_identity` named `${var.project}-${var.environment}-identity` in `var.resource_group_name`, `var.location`, `local.tags`
- `variables.tf`: `project`, `environment`, `resource_group_name`, `location`, `tags`
- `outputs.tf`: `id`, `principal_id`, `client_id`, `name`

____

**Module: acr**
- `main.tf`: `azurerm_container_registry` — name `${var.project}${var.environment}acr` (alphanumeric only), SKU from `var.sku` (default `"Basic"`), `admin_enabled = false`, `local.tags`. Add `azurerm_role_assignment` granting `AcrPull` to `var.identity_principal_id` on the ACR.
- `variables.tf`: `project`, `environment`, `resource_group_name`, `location`, `sku` (default `"Basic"`), `identity_principal_id`, `tags`
- `outputs.tf`: `login_server`, `id`, `name`

____

**Module: keyvault**
- `main.tf`: `azurerm_key_vault` — name `${var.project}-${var.environment}-kv` (max 24 chars), `sku_name = "standard"`, `enable_rbac_authorization = true`, `soft_delete_retention_days = 7`, `purge_protection_enabled = true`, `local.tags`. Add `azurerm_role_assignment` granting `Key Vault Secrets User` to `var.identity_principal_id`.
- `variables.tf`: `project`, `environment`, `resource_group_name`, `location`, `tenant_id`, `identity_principal_id`, `tags`
- `outputs.tf`: `id`, `name`, `vault_uri`

____

**Module: sql**
- `main.tf`:
  - `azurerm_mssql_server` — name `${var.project}-${var.environment}-sql`, `version = "12.0"`, `administrator_login` from `var.admin_login`, `administrator_login_password` from `var.admin_password` (sensitive), `minimum_tls_version = "1.2"`, `public_network_access_enabled = true` (required for Container Apps without VNet), `local.tags`
  - `azurerm_mssql_database` — name `teamtasks`, attached to the sql server, `sku_name = var.db_sku` (default `"Basic"` for dev, override to `"S1"` for prod), `max_size_gb = 2`
  - `azurerm_mssql_firewall_rule` — name `AllowAzureServices`, start/end ip `0.0.0.0` (enables "Allow Azure Services" checkbox)
- `variables.tf`: `project`, `environment`, `resource_group_name`, `location`, `admin_login` (sensitive), `admin_password` (sensitive), `db_sku` (default `"Basic"`), `tags`
- `outputs.tf`: `server_fqdn`, `database_name`, `connection_string` (sensitive) — format: `"Server=tcp:${azurerm_mssql_server.this.fully_qualified_domain_name},1433;Initial Catalog=teamtasks;User ID=${var.admin_login};Password=${var.admin_password};Encrypt=True;TrustServerCertificate=False;"`

____

**Module: app**
- `main.tf`:
  - `azurerm_log_analytics_workspace` — for Container Apps environment telemetry
  - `azurerm_container_app_environment` — linked to log analytics workspace, `local.tags`
  - `azurerm_container_app` — name `${var.project}-${var.environment}-api`, revision mode `Single` for rolling, identity block using `var.identity_id` (user-assigned), ingress with `external_enabled = true`, `target_port = 8080`, transport `auto`. Template with a single container: image `${var.acr_login_server}/${var.image_name}:${var.image_tag}`, resource limits `cpu = 0.5, memory = "1Gi"`. Set env var `ASPNETCORE_ENVIRONMENT` = `var.aspnet_environment` (default `"Production"`). Set `ConnectionStrings__DefaultConnection` from `var.db_connection_string` (mark as secret ref).
- `variables.tf`: `project`, `environment`, `resource_group_name`, `location`, `identity_id`, `acr_login_server`, `image_name` (default `"teamtasks-api"`), `image_tag` (default `"latest"`), `db_connection_string` (sensitive), `aspnet_environment` (default `"Production"`), `tags`
- `outputs.tf`: `app_fqdn`, `app_id`, `environment_id`

____

Do NOT add provider blocks inside modules. Modules inherit the provider from the root env config.
