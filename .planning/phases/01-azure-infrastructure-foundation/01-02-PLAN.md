<objective>
Migrate the backend from SQLite to Azure SQL Database by swapping the EF Core provider and updating the connection string strategy.

Purpose: SQLite is a local file — it cannot be shared across Container App replicas (rolling deployments require a network-accessible DB). This task makes the backend cloud-ready.
Output: Backend compiles with `Microsoft.EntityFrameworkCore.SqlServer`, tests still pass, no SQLite dependency remains, no credentials in source.
</objective>

**1. TeamTasks.Api.csproj** — remove the SQLite package reference, add SqlServer:
```xml
<!-- Remove: -->
<PackageReference Include="Microsoft.EntityFrameworkCore.Sqlite" Version="10.0.5" />

<!-- Add: -->
<PackageReference Include="Microsoft.EntityFrameworkCore.SqlServer" Version="10.0.5" />
```

**2. Program.cs** — change `UseSqlite` to `UseSqlServer` (single word change, same line):
```csharp
options.UseSqlServer(connectionString);
```

**3. appsettings.json** — replace the SQLite file path with an empty placeholder. The real value will be injected as environment variable `ConnectionStrings__DefaultConnection` by Container Apps at runtime. NEVER put a real connection string with credentials in this file:
```json
{
  "ConnectionStrings": {
    "DefaultConnection": ""
  }
}
```

**4. appsettings.Development.json** — add a localdb connection string for local development (uses LocalDB/SQL Server Express — developer must have SQL Server LocalDB installed, OR can use Docker: `docker run -e ACCEPT_EULA=Y -e SA_PASSWORD=Dev@local123 -p 1433:1433 mcr.microsoft.com/mssql/server:2022-latest`):
```json
{
  "ConnectionStrings": {
    "DefaultConnection": "Server=(localdb)\\mssqllocaldb;Database=teamtasks;Trusted_Connection=True;MultipleActiveResultSets=true"
  }
}
```

**5. DbInitializer.cs** — keep `EnsureCreatedAsync()` for now (acceptable for this milestone's demo scope; EF migrations are noted in CONCERNS.md as future work). No change needed to this file unless the current code has a SQLite-specific import — remove any `using Microsoft.Data.Sqlite;` if present.
