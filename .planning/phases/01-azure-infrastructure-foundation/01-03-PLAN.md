Add `oidc.tf` to the identity module and extend variables/outputs to support GitHub Actions OIDC federation (SEC-02: no long-lived service principal secrets).

**infra/modules/identity/oidc.tf:**
```hcl
# GitHub Actions OIDC federated identity credentials
# Allows GitHub Actions to authenticate to Azure without client secrets
# One credential per GitHub environment (dev, prod)
resource "azurerm_federated_identity_credential" "github" {
  for_each = toset(var.github_environments)

  name                = "github-${each.value}"
  resource_group_name = var.resource_group_name
  parent_id           = azurerm_user_assigned_identity.this.id
  audience            = ["api://AzureADTokenExchange"]
  issuer              = "https://token.actions.githubusercontent.com"
  subject             = "repo:${var.github_repo}:environment:${each.value}"
}
```

**Add to infra/modules/identity/variables.tf:**
```hcl
variable "github_repo" {
  description = "GitHub repository in owner/repo format for OIDC federation"
  type        = string
}

variable "github_environments" {
  description = "GitHub Actions environment names to create OIDC credentials for"
  type        = list(string)
  default     = []
}
```

**Add to infra/modules/identity/outputs.tf:**
```hcl
output "federated_credential_ids" {
  description = "Map of GitHub environment name to federated credential resource ID"
  value       = { for k, v in azurerm_federated_identity_credential.github : k => v.id }
}
```

Also add an `azurerm_role_assignment` resource to the identity module's `main.tf` granting `Contributor` role to the managed identity on the resource group (required for GitHub Actions to deploy resources):

```hcl
resource "azurerm_role_assignment" "contributor" {
  scope                = var.resource_group_id
  role_definition_name = "Contributor"
  principal_id         = azurerm_user_assigned_identity.this.principal_id
}
```

Add `resource_group_id` variable to `variables.tf`:
```hcl
variable "resource_group_id" {
  description = "Resource group ID for Contributor role assignment"
  type        = string
}
```

  environment         = var.environment
